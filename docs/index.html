What it does

Old versions actually run

1.8 and 1.12 need Java 8, and nobody has Java 8 lying around. Astra reads what each version asks for and fetches that exact runtime from Mojang, so the launchwrapper crash everyone hits simply never happens.

Snapshots install cleanly

Modern versions list native libraries for three CPU architectures under one rule. Astra matches them to your machine instead of grabbing whichever came first - the usual cause of a snapshot refusing to download.

Mods and shaders built in

Search everything on Modrinth, filtered to your profile's loader and version. Required dependencies come along automatically, which is the fix for the most common "modded profile won't start" problem.

Friends you can join

See who is online, what they are playing and where. One button puts you on the same server.

Updates measured in kilobytes

The runtime never changes, so only the code that did is downloaded. A normal update is about 42 KB rather than reinstalling 80 MB.

Real performance work

Presets that set genuine JVM flags and write Minecraft's own options, from Quality down to Potato PC. Honest latency to every server in your list - no spoofing.

Capes that move

Live capes are real video, not a flipbook - a whole scene moving on your back.

Cosmetics are earned with coins from daily challenges. There is no way to buy coins with money, on purpose.

Share a setup with a code

Turn a whole profile - version, loader and every mod in it - into six characters. Paste one here to see what is inside before you import it.

Codes use no vowels and no look-alike characters, so they survive being read aloud.
